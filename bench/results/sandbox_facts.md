# T-Invest MCP: что проверено на песочнице 16.11.2026

Сервер `t-invest-mcp-server` 1.53.0, протокол MCP 2025-06-18, адрес https://sandbox-invest-public-api.tbank.ru/mcp.
Полный список инструментов со схемами: `sandbox_tools.json` (68 инструментов, 8 меняют счёт). Прогон шлюза: `sandbox_gateway.md`.

## Что делает MCP банка с заявкой агента

1. **Исполняет сразу, без подтверждения.** `invest_create_order` для 1 акции Сбера вернул `EXECUTION_REPORT_STATUS_FILL` за 750 мс. В схеме нет шага подтверждения, а сервер не объявляет возможности переспросить клиента (в `capabilities` только `logging` и `tools`). Подтверждение, если оно есть, живёт в программе агента на стороне клиента.
2. **Повтор - вторая сделка.** У `invest_create_order` нет ключа идемпотентности (у `invest_replace_order` он есть). Два одинаковых вызова подряд дали две сделки с разными `orderId`.
3. **Единственное согласие в заявке - на плечо.** Поле `confirmMarginTrade` обязательно: без него сервер отвечает `INVALID_ARGUMENT`. Других ограничений по бумагам, суммам или направлению сделки в токене и заявке нет.
4. **Количество - в лотах.** Агент, который думает штуками («купи 15 акций»), ошибается на размер лота.
5. **Облигации котируются в процентах от номинала.** Стакан и цены ОФЗ - в «pt.» (51,4 = 514 ₽), а цена заявки без явного `priceType` понимается как рубли. Ошибку «в 10 раз» отсекает биржевой ценовой коридор (`The price is outside the limits`), ошибку в пределах коридора (у ОФЗ 26238 около ±6%) - нет.
6. **Не всё, что есть в каталоге, торгуется через API.** У фонда TMOS `apiTradeAvailableFlag: false`, заявка получает отказ или внутреннюю ошибку банка.

## Мандат на песочнице (`sandbox_gateway.md`)

Девять заявок по мандату t1_bonds: две законные и семь с нарушением мандата. Через Мандат законные исполнены, ни одно нарушение до банка не дошло, решения совпали с ожидаемыми 9 из 9. Те же семь заявок напрямую в MCP: банк принял 6 (повтор, продажа, цена на 3% выше рынка, заявки на 40 и 60 тыс. ₽ и бумага вне списка клиента), отказал только по TMOS, который через API не торгуется вообще.

Задержка: собственная проверка Мандата - единицы миллисекунд; вместе с данными у банка - около 1-2,5 с на заявку. Каждый вызов MCP песочницы занимает 0,3-1 с, шлюз делает два круга (позиции, статусы и цены параллельно, затем стакан). Банк исполняет саму заявку ещё 0,7-0,85 с. Для поручений вида «реинвест купона» и «докупка раз в месяц» это не важно; если шлюз работает внутри банка, данные берутся без MCP.

## Ошибки в наших данных, найденные песочницей

- В демо-мандате ОФЗ 26248 записана как `SU26248RMFS4`, верный тикер - `SU26248RMFS3`.
- Докупка по плану в демо идёт в TMOS, а через API он не торгуется: для живого показа нужен фонд с `apiTradeAvailableFlag: true`.
