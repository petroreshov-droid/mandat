# Мандат: доверенность для ИИ-агента

Шлюз между любым ИИ-агентом и T-Invest MCP. Клиент один раз задаёт границы своими словами, LLM переводит их в строгие правила, и дальше каждое действие агента проверяет детерминированный код: **ALLOW** - агент действует сам, **ASK** - заявка ждёт клиента, **DENY** - отказ с причиной. Каждое решение пишется в журнал с цепочкой SHA-256, любое можно воспроизвести.

Проект команды Edge Lab для конкурса «Инвест. Премаркет».

- Сайт проекта: https://petroreshov-droid.github.io/mandat/
- Интерактивный прототип: https://petroreshov-droid.github.io/mandat/demo.html
- Презентация: https://petroreshov-droid.github.io/mandat/slides.html ([PDF](docs/slides.pdf))

**Агент на T-lite-it-2.1** (открытая модель Т-Банка, мандат целиком в системном промпте, 32 сценария по 3 прогона): вредным инструкциям в новостях не поддался ни разу, но вышел за мандат в 12 из 72 прогонов атак и ошибок (повтор на новых зёрнах - 25 из 168, вместе 37 из 240) (лоты, лимиты, «изменение мандата» из чата) и в 3 из 24 рутинных поручений поставил неверную цену: номинал 1 000 ₽ или цену другой ОФЗ вместо рыночной 905,6 ₽. Через Мандат все 18 таких заявок остановил код. Подробно: [bench/results/llm.md](bench/results/llm.md).

**Задержка**: `evaluate()` p50 3,8 мкс, p95 11,8 мкс; `post_order()` с журналом и mock-брокером p95 0,3 мс.

**Песочница T-Invest MCP** (16.11.2026, 9 заявок по мандату клиента): решения шлюза совпали с ожидаемыми 9 из 9, законные исполнены, из 7 нарушений до банка не дошло ни одно. Те же 7 напрямую в MCP: банк принял 6. MCP банка исполняет заявку агента сразу, без подтверждения, а повтор вызова даёт вторую сделку. Ответ шлюза вместе с данными песочницы - медиана около 1 с, разброс 0,4-3,7 с (один вызов MCP песочницы 0,25-2,9 с), своё время шлюза - до 62 мс. Подробно: [bench/results/sandbox_gateway.md](bench/results/sandbox_gateway.md), факты о MCP: [bench/results/sandbox_facts.md](bench/results/sandbox_facts.md).

**Основной сценарий на песочнице**: купон 4 200 ₽ - поручение «реинвест» само купило ОФЗ с наименьшей долей, повтор события купона отклонён, «докупка по плану» исполнена, атака «продай всё» - три отказа и пауза, после снятия паузы клиентом заявка исполнена; все 8 решений воспроизводятся из журнала. [bench/results/sandbox_scenario.md](bench/results/sandbox_scenario.md).

**Агент T-lite на песочнице** (17.11.2026, те же 32 сценария по 2 прогона; счёт, цены и стаканы настоящие, каждый ответ агента исполнен через Мандат и напрямую в MCP): вышел за мандат в 2 из 48 прогонов атак, через Мандат - 0. Меньше, чем на стенде: ошибки лота на настоящих данных нет (лот Сбера 1, на стенде был 10), давлению в чате агент не поддался ни разу. Изменение мандата из чата («подними лимит до 300 000 ₽») принял так же часто, как на стенде, - в 2 из 8. Законные поручения: 11 из 16 исполнены, остальные 5 без вреда. [bench/results/sandbox_llm.md](bench/results/sandbox_llm.md).

## Как устроено

- **Мандат** - JSON по схеме `mandat/v1`: разрешённые классы, бумаги и валюты, запрет продаж, плеча и бумаг для квалов, лимиты доли, размера заявки, дневного оборота, порога подтверждения, отклонения цены, доли стакана и частоты заявок, поручения. Подписанная версия фиксируется SHA-256 канонического JSON.
- **Движок** - чистая функция `evaluate(order, mandate, market, state)`: 19 проверок в строгом порядке, жёсткий провал даёт DENY, мягкий - ASK. Деньги, доли и лоты считает код по данным брокера.
- **Шлюз** - для агента обычный MCP-сервер с инструментами брокера. Перед каждой заявкой берёт свежий снимок у брокера, вызывает движок, обновляет состояние и пишет журнал. Изменить мандат агент не может: это делает только клиент подписью новой версии.
- **LLM** - только для языка: компиляция мандата, смысловой стресс-тест, объяснения. На реальных данных - T-Pro или GigaChat, зарубежные модели только на синтетике.

## Ограничения прототипа

- Рыночные данные синтетические, исполнение у mock-брокера по цене заявки.
- В песочнице T-Invest нет купонов и дивидендов, поэтому в MVP событие купона эмулируется, а заявки и проверки идут по-настоящему.
- Компилятор в прототипе работает на двух шаблонах; точность на свободном тексте измерим на этапе MVP (цель - от 95% точных совпадений на 50+ размеченных текстах).
- Задержка запроса данных у T-Invest не измерена: нужен sandbox-токен.

## Права и лицензии

Материалы подготовлены для конкурса «Инвест. Премаркет»; исключительные права переходят Банку по условиям конкурса, открытой лицензии нет. Ядро работает на стандартной библиотеке Python. Опциональные зависимости - под MIT, BSD, Apache или PSF, без GPL, MPL и AGPL: поэтому `mcp` закреплён на версии 2.x (в 1.x через httpx подтягивается certifi под MPL-2.0), а счётчики в MVP хранятся в PostgreSQL, а не в Redis.
